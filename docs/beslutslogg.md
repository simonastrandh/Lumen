# Beslutslogg

Logga nya beslut här löpande UNDER bygget, med datum. De filer som redan finns i den
här mappen (brief, prioritering, ai-roll, teknisk-avgransning-och-risker,
fragor-och-svar) är förarbetet från planeringsfasen i Figma — uppdatera dem om ett
tidigare beslut ändras, och lägg nya beslut som rader här.

## Format
`YYYY-MM-DD – Beslut: ... | Varför: ... | Alternativ som övervägdes: ...`
